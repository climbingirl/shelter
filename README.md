# Shelter

Это многостраничный адаптивный сайт приюта для животных, разработанный с использованием HTML, SCSS, CSS и JavaScript. Сайт состоит из нескольких страниц, включая главную и страницу с информацией о питомцах.

## GitHub Pages

[https://climbingirl.github.io/shelter/index.html#help](https://climbingirl.github.io/shelter/index.html#help)

## Функциональность

- **Многостраничность**  
  
- **Адаптивное меню**  
  Меню автоматически подстраивается под различные размеры экранов - от больших мониторов до мобильных устройств. Это обеспечивает удобную и понятную навигацию на любом устройстве.

- **Слайдер**  
  Интерактивный слайдер позволяет динамично демонстрировать фотографии питомцев и важные сообщения с плавными переходами и элементами управления.

- **Попапы (всплывающие окна)**  
  Используются для отображения дополнительной информации о питомцах.

## Технологии

- HTML5
- SCSS / CSS3
- JavaScript (ES6+)
